PickStash · Design System v1 제안

다정한 손그림 창고

대화는 흘러가도 결정은 남도록. 핀터레스트 보드 3개(메인·로고·다크모드)와 로고에서 추출한 방향을 하나의 시스템으로 정리했습니다. 화면 구성은 현재 코드가 아니라 Excalidraw 와이어프레임을 기준으로 삼았습니다.

크림 + 잉크 + 버터 손그림 위트 blob 셰이프 스탬프 피드백 이모지 아이콘 다크모드 = 차콜 + 버터
01

컬러

배경은 로고의 크림(#FAFBEB 계열)을 그대로 물려받고, 순수 검정 대신 로고의 웜 잉크를 씁니다. 기존의 파랑 계열 액션 컬러는 전부 버터 옐로우·잉크 체계로 교체합니다. 초록·주황·빨강은 상태 의미 전용입니다.

02

타이포 · 셰이프

타이포그래피

  • 서체Pretendard (웹폰트 번들 권장)
  • 화면 제목19–20px · ExtraBold · -2% 자간
  • 카드 제목15–16px · ExtraBold
  • 본문13–14px · Regular
  • 메타11–12px · ink-faint
  • 숫자tabular-nums (카운트·D-day)

라디우스 — 뭉툭하게

  • 카드20px
  • 버튼·입력16px
  • 패널·시트24px 이상
  • 뱃지·칩full (999px)

일러스트 · 위트

  • 캐릭터로고 창고 캐릭터를 빈 상태·온보딩에 확장
  • 스탬프결정 완료 순간에 도장 찍기
  • 아이콘이모지 우선, 부족하면 2px 잉크 라인
  • 마이크로카피"아직 들썩이는 상자가 없네요" 톤 유지
