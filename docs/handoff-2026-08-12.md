## 2. ⚠️ 이어서 할 핵심 결정 — 서랍 공유 모델 재설계 (미착수, 합의됨)

**문제의식(사용자 피드백):**
- "나만 보기"는 **초대된 사람을 빼는 게 아니다.** 그건 "이 상자를 이 서랍에 담았다는 걸 나만 볼지"의 문제(= *담기 가시성*)이고, **상자 참여(누가 편집 가능한가)와는 별개**다. → 045의 참여자 제거 로직은 틀림.
- 한 상자를 여러 공유서랍에 담으면 **각 서랍 멤버가 다 자동초대**돼서 한 상자에 사람이 눈덩이처럼 붙는다. 이게 이상하다.

**확정 방향 (담기 ≠ 초대, 완전 분리):**
> 서랍은 공유 폴더. 상자를 담으면 서랍 멤버에게 **보이긴 하되(목록+읽기전용), 자동 참여는 아님.** 편집·투표하려면 **"참여 신청"→승인**. 그전엔 **둘러보기(읽기전용) 모드**로 본다. **나만 담기 = 나만 봄(멤버 목록에도 안 뜸).**
- 이미 만든 걸 재활용: **읽기전용 뷰어**(`/p`·초대뷰어)와 **참여 신청 흐름**(`request_to_join`/`respond_join_request`, 041/046).
- 멀티폴더 자동초대 폭발 문제 → 자동초대 자체가 없어지니 해소.

**구현 범위 (다음 세션 = 마이그레이션 047 + 앱):**
1. **자동초대 트리거 제거**: `folder_box_added_join`·`folder_member_added_join`(담기/멤버합류 시 참여자 자동 추가) 폐기.
2. **상자 읽기 RLS 확장**: 참여자가 아니어도 **내가 멤버인 서랍에 `shared=true`로 담긴 상자**는 SELECT 가능하게.
3. **상자 상세**: 참여자 아니면 **읽기전용 + "참여 신청" 버튼**(`request_to_join` 이미 있음).
4. **`set_box_folder_shared`**: 참여자 건드리지 말고 **가시성 플래그만** 토글(045의 참여자 add/remove 폐기).
5. **`box_folders.added_by`** 추가: 나만 담기(`shared=false`)를 담은 사람만 보이게(폴더뷰·초대뷰어 필터 + RLS).
6. **기존 자동초대 참여자는 그대로 둠**(제거 안 함 — 무손실 전환).
7. **나만→공유 전환 시** "이 서랍 사람들에게 보이게 할까요?"만 — 자동 참여는 없음(신청 기반이라).

**미완 UI (이 모델 확정 후 재작업):**
- 상자 상세 **폴더 피커 스테이징 모달**: 지금은 체크 즉시 반영이라 불편 → **체크는 draft로만, "완료" 눌러야 반영**, 각 폴더 행에 **공개/나만 스위치를 체크 왼쪽에**. (작업하다 모델 재논의로 중단, `getMyBoxFolders`(shared 포함) 리네임은 원복해둠.)
