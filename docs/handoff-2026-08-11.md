## 0. 기본
- **브랜치**: `feature/toss-integration` (main 자동배포 대상 아님 — 웹 운영 안전)

- **빌드**: `.ait` = `cd toss && npm run build` → deploymentId 나옴 → 콘솔 업로드. 웹 dev = `npm run dev`(https, 8888은 토스 dev).
- **검증**: `npm run build`(웹) + `cd toss && npx tsc -p tsconfig.app.json --noEmit && npm run build`(토스) 둘 다 통과 확인된 상태로 커밋됨.

### 소셜 M1~M3 + 홈 서랍 레일 최초 반영 — 이전 세션 완료(자세한 건 git log 참고)

### 오늘 추가로 진행한 것 — 서랍 레일 다듬기 + 상자 카드 전체 통일
- **히어로**: 좋아요·댓글 수 제거(참여자 아바타·CTA·D-day는 유지).
- **`BoxSummaryCard`**(`src/components/box-summary-card.tsx`) — 서랍 레일 상자 카드 확정판:
  모드 칩·즐겨찾기 별·정리됨 배지 없음, D-day 배지(긴급도 색), 체크형은 "N/M 체크" 텍스트만(진행바 없음),
  결정형은 인기 리더 배지 또는 "선택지 N개"(리더 없을 때 허전함 방지, `total`은 옵션 개수라 결정형도 항상 값 있음),
  정리완료는 형광펜 강조+"(으)로 결정!"(이름 굵게/접미사 얇게), **하단에 참여자 행 추가**(아바타+"N명 참여 중"
  또는 "혼자 쓰는 상자" — `/boxes` 탭 옛 `BoxCard`와 동일 문구·스타일로 통일). 닫힘+결정없음 edge case는
  배지 없이 옅은 텍스트 "결정 없이 마감".
- **`RecapCard`**(닫힌 상자, `lib/domain/home.ts`)에 `mode`·`participants` 필드 추가 — `loadHomeView`의
  `doneRecap` 쿼리를 `buildBoxCards` 태우도록 재작성해서 열림/닫힘 카드가 완전히 동일한 계산을 공유.
- **`서랍 레일`**(`drawer-rail.tsx`): "최근 활동순"/"전체 보기" 라벨 폰트 13px로, 상자 제목 17px로 확대.
  서랍 선택 시에도 "전체 보기"(→ `/folder/[id]`) 노출(비어있을 때는 카드 자체가 그리로 링크되니 중복 방지로 숨김).
  빈 서랍 카드는 `options-section.tsx` 빈 상태 톤(점선+원형 아이콘 배지)으로, 누르면 `/folder/[id]`로 이동.
  "전체" 칩 라벨 "전체" → **"전체 상자"**(box 아이콘과 헷갈리지 않게).
- **`loadAllBoxCards`**(신규, `src/lib/api/box-list.ts`) — `/boxes`(상자) 탭도 홈과 완전히 같은
  `BoxSummaryCard`를 쓰도록 `buildBoxCards` 기반 새 로더 추가. 쿼리 키는 기존 `["box-list","all"]` 그대로
  유지해서 `use-boxes.ts`/`use-favorites.ts`의 기존 무효화가 계속 커버함. `/messy`·`/done`·`/favorites`는
  안 건드림(옛 `loadBoxList`/`BoxCard` 그대로).
- **상자 탭 재설계**(`toss/src/screens/boxes-screen.tsx`): 헤더에 **"상자 | 서랍" 2단 세그먼트 토글**(선택 시
  검정 배경) 추가 — 탭바에 서랍 탭을 새로 안 만들고(자리 부족, 토스는 하단 탭바가 유일한 1차 내비) 기존 "상자"
  탭 안에서 전환. "상자" 모드에서만 그 아래 종류 칩(전체/**결정형**/**체크형** — "결정"만 쓰면 "이미 결정된"으로
  오해될 수 있어 "~형" 붙임) 노출. "서랍" 모드는 실제 `/folders` 페이지와 톤 통일한 2열 그리드 카드(버터틴트+
  아바타/혼자쓰는서랍 표기) — 관리(이름변경·나가기·초대)는 여전히 `/folders`·`/folder/[id]`가 전담, 여긴 보기+이동만.
- **`돋보기`**(`explore-view.tsx`)의 `PublicBoxRow`도 `BoxSummaryCard` 시각 언어로 통일(모드 칩 제거, 제목
  17px, "선택지 N개" 폴백 — `PublicBoxCard`엔 참여자·리더·마감 데이터가 없어(대신 author·save_count) 컴포넌트
  재사용은 못 하고 스타일만 이식).
- **홈 인라인 광고**: 하단 고정 배너(`AdBanner`)를 홈에서만 빼고, 히어로 카드 아래 인라인 배너(`InlineAdBanner`,
  신규)로 교체(다른 화면 알림 등은 고정 배너 유지). `TossAds.initialize` 싱글톤은 `toss/src/lib/toss-ads.ts`로
  공용 추출(고정+인라인 배너가 각자 부르면 중복 초기화라 위험했음). `toss/src/App.tsx`의 `showBanner`도
  `/alerts`에서만 켜지도록 축소.
- 목업(`src/app/mockup/`) 정리·`/boxes` 스왑 원복은 이전 커밋에서 이미 완료.
