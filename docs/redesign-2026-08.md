# 결정창고 화면·기능 개편안 (통합 정리 · 최종)

> 체크형 상자 도입 + 소셜(인스타식) 전환으로 나온 개편안을 한 문서로 정리한다.
> **출시: 소셜까지 한 번에**(단계 분리 없음, 큰 릴리즈).
> 상태: ✅확정 / 🔷설계-시 세부. (작성 2026-08)

## 0. 배경
- 체크형 상자(`box.mode==='checklist'`)가 홈·탭바·필터의 결정형 전제와 안 맞음(상세 외 미반영).
- 진행중/정리됨 분리의 효용이 낮음.
- 방향 전환: 인스타처럼 **남의 공개 결정을 구경·검색·참고**하고 팔로우/북마크.

## 1. 확정 결정 (8)
1. **홈 = 내 작업공간** (아래 "홈·대시" 유지). 남 구경·팔로잉은 돋보기/프로필에서.
2. **탭바 4개: 홈 / 돋보기 / 알림 / 프로필.** 상자·서랍 탭 제거. 서랍은 홈에서 "그룹 카드"로 노출. 새 상자 = 홈 FAB.
3. **공개 = 상태 무관, 상자별 공개 토글.** 기본 전부 비공개, 내가 공개한 것만 프로필 피드/탐색에 노출(보관함).
4. **참여자 프라이버시**: 혼자 상자=전체 공개, 여럿 상자=**남 익명화**(내 것만 온전히, 남 닉네임·아바타·댓글작성자 가림, "N명 참여"). 훗날 '실명 공개 동의' 옵션 여지.
5. **관계 = 팔로우(단방향, 인스타식).** 상자 합류는 별개의 **참여 신청→승인**.
6. **사용자명 @handle 도입**(고유, 최초 1회 설정). 프로필 URL·검색·멘션용. 닉네임=표시명 유지.
7. **가벼운 태그(자유 입력)** — 공개 시 태그, 탐색 주제별 둘러보기.
8. **즐겨찾기 → 북마크로 재정의**: 남의 공개 상자를 저장. 저장 목록은 **프로필 안 '저장함' 탭**. 홈 "내 상자" 스트림엔 별표 개념 없음(최근 활동순만).

## 2. 화면 설계

### 2-1. 상태 모델 ✅
- `closed_at` 파생 정리완료는 유지하되 **진행/정리로 화면을 나누지 않음**. 단일 스트림 + 정리됨은 카드 배지.

### 2-2. 홈 (내 작업공간) ✅
순서: ① 마감 임박 히어로(마감투표 임박 시에만) → ② **서랍 = 그룹 카드**(멤버·상자수 보이게) → ③ **내 상자 스트림**(최근 활동순, 정리됨 배지) → 하단 **새 상자 FAB**.
- 체크형 카드: 좋아요/1위/마감 대신 **진행률(N/M + 바)**.

### 2-3. 탭바 ✅
- 홈 / 돋보기 / 알림 / 프로필 (돋보기·프로필 = 소셜, 동시 출시).

### 2-4. 돋보기(탐색) ✅
- 검색(공개 상자 + 사람) + 인기/최근 공개 피드. 태그 주제별 둘러보기. 사람 결과에 팔로우 버튼.

### 2-5. 프로필(인스타식) ✅
- 헤더: 아바타 · @handle · 소개 · 공개수/팔로워/팔로잉 · (남이면) 팔로우 버튼.
- **공개 상자 그리드**(결정=결과, 체크=진행). 내 프로필엔 **'저장함'(북마크) 탭**.
- 남의 공개 상자 진입 → 읽기전용 뷰어 + **참여 신청** 버튼.

## 3. 신규 백엔드 (greenfield · 규모 큼)
현 코드는 참여자 전용 RLS + invite-code definer뿐이라 아래 전부 신규:
- `boxes.visibility`(공개/비공개) + 태그 저장.
- **공개 주체** 개념 재도입(owner_id는 011에서 제거됨) — 공개자 표현.
- **공개 열람 경로**: 공개 상자용 조회 RPC/정책(`014 get_box_view_by_invite_code` definer 패턴 재사용) + **여럿 상자 남 익명화** 로직.
- `follows(follower_id, followee_id)` + RLS + 카운트.
- **@handle**: profiles에 unique handle 컬럼 + 설정 UI + 검색 인덱스.
- **검색**: 공개 상자(제목·태그)·사람(handle·닉네임) 인덱스.
- **북마크**: `bookmarks(user_id, box_id)` + '저장함' 조회.
- **참여 신청·승인**: `join_requests`(pending) + RLS(외부인 신청 insert, 참여자 승인) + RPC + 알림. (지금은 insert=즉시 정회원.)
- **알림 확장**: 팔로우·참여신청·승인 타입.
- 프로필/탐색 라우트(웹 `/u/[handle]` 등 + 토스 화면).
