# 결정창고 (PickStash)

## 💡서비스 소개

### 대화는 흘러가도, 결정은 남도록 “결정창고”

카카오톡 대화방에서 주고받는 수많은 맛집 링크, 모임 장소, 사고 싶은 아이템들.
대화가 쌓이면 금방 위로 올라가 버리고, 나중에 다시 찾으려면 한참을 스크롤해야 하죠.
투표 결과는 시간이 지나면 사라지고, 중요한 의견들은 대화 속에 섞여 흐지부지되기 일쑤입니다.

**결정창고**는 이런 번거로움을 해결하기 위해 태어났습니다!

- **Stash (수집)**: 링크와 사진을 주제별 보드에 깔끔하게 모아둡니다.
- **Discuss (논의)**: 각 후보별로 댓글을 달아 대화가 섞이지 않게 정리합니다.
- **Decide (투표)**: 직관적인 투표로 최선의 선택을 함께 결정합니다.
- **Archive (보관)**: 확정된 결과와 고민의 과정을 우리만의 소중한 기록으로 남깁니다.

이제 **결정창고에서** 쉽게 모으고, 함께 고르고, 오래 기억하세요.
